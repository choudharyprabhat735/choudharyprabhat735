### 🛡️ Flagship: Intelligent Automotive Gateway & Intrusion Detection System
![STM32F446RE](https://img.shields.io/badge/STM32F446RE-03234B?style=flat-square&logo=stmicroelectronics&logoColor=white) ![CAN](https://img.shields.io/badge/CAN-1F6FEB?style=flat-square) ![Embedded C](https://img.shields.io/badge/Embedded%20C-00599C?style=flat-square&logo=c&logoColor=white) ![Sep 2026](https://img.shields.io/badge/Sep%202026-555?style=flat-square)

An STM32-based **CAN security gateway** that inspects vehicle messages, **allows valid IDs, and blocks unauthorized ones**, with real-time **intrusion alerts** on LCD and LED indicators. Message filtering is implemented in Embedded C.

```mermaid

    E --> F["🚨 LCD + LED intrusion alert"]
```
